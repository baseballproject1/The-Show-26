# Road to the Majors

Original browser RTTS-style baseball game.

## GitHub Pages
1. Upload `index.html`, `css/`, `js/` to a repository.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Open the generated Pages URL.

## Current systems
- Minor League → MLB career
- 30 MLB team names
- 5 stats: Contact / Power / Clutch / Running / Defense
- Starting 250 tokens, manual allocation
- Training success grants 1 token
- Equipment: glove / shoes / bat / batting gloves / protective gear
- 5 equipment rarities
- Salary negotiation and equipment spending
- Direct batting zone + swing
- Manual baserunning
- Manual fielding + throw aim
- Manual pitching
- ABS review: 2 per game; overturned = retained, upheld = -1
- 3 save slots with localStorage
- Korean UI foundation
